CaptureViewer - Windows x64 portable build

1. Extract the complete downloaded ZIP into a writable folder on Windows 11 x64.
2. Connect your HDMI capture device and install its drivers if required.
3. Run viewer.exe. A Direct3D 12 capable GPU is required.
4. Press M to open the ImGui settings menu:
   Display: windowed/borderless/fullscreen, VSync, HUD and preview scaling.
   Capture: device, resolution, frame rate and pixel format.
   Audio: input, monitoring and output devices.
5. Press F11 to toggle fullscreen; F10 toggles the top latency/FPS overlay.
6. Choose Fit, Stretch, Native, Fill/crop, or Custom 25-200% source scaling.
   Custom 100% maps one source pixel to one display pixel. It does not change
   the capture resolution. Close the menu for high-frame-rate playback.

Frame-rate selection (v1.1.1):
- M > Capture > Capture Format: Auto, choose resolution, then Requested Capture FPS.
- The FPS list reads the selected driver's mode and frame-interval capabilities.
- Active capture mode shows the negotiated setting; the top CAPTURE FPS is measured.
- Driver rejection or fractional-rate rounding is explained in the Capture tab.
- If only 60 FPS is available, try another format/resolution. Refresh devices and
  modes restarts capture and rereads the driver's capabilities.

The preview keeps the latest received frame and skips older frames rather than
playing a delayed queue. VSync defaults off unless an existing settings file
enables it. Skipped counts old frames bypassed by the application.

APP LATENCY measures the local capture callback through the return of Present.
It excludes capture-card/USB latency and actual GPU scanout/screen latency.
CAPTURE FPS is received video frames; PREVIEW FPS counts newly submitted frames,
not repeated overlay redraws. FPS readings update about twice per second.

The application saves settings.json beside viewer.exe. Fonts, icons and shaders
are embedded. This build statically links the MSVC C++ runtime.

The GitHub Actions build verifies that viewer.exe is a 64-bit Windows executable.
It does not verify HDMI capture, GC553G2 compatibility, latency or 240 FPS output;
these must be tested with the actual Windows PC, GPU and capture device.

See BUILD-INFO.txt for the source commit and build URL, SHA256SUMS.txt for the
executable checksum, and README.md for more project details.
